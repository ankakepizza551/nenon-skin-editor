# Minecraft Skin Editor

Minecraft（Java版）のスキンを描いて、3Dで確認しながら PNG に書き出すエディタです。
React + TypeScript + Vite + Three.js 製で、Electron でデスクトップアプリとして配布できます。

## 機能

- 64×64 スキンの編集（ペン / 消しゴム / 塗りつぶし / スポイト）
- 左右対称描画（M キー）：ペンと消しゴムが、キャラクターの左右対称の位置にも効きます。頭と胴は同じパーツ内で折り返し、腕と脚は反対側の手足に写ります
- 3Dモデルに直接描画：プレビューのモデル上をドラッグすると、選択中のツールでそのまま描けます。描く先（ベース／重ね着）はプレビュー上部で切り替えます。余白のドラッグか右ドラッグで回転します
- 色むら（N キー）：ペンと塗りつぶしの色を、1ピクセルごとに少しだけ明るく／暗くばらつかせます
- ポーズ切り替え：プレビュー上部で「立ち／歩行／広げ」を選べます。歩行は腕と脚を振るアニメーション、広げは腕を横に伸ばして脚を少し開いた姿勢で、腕の内側や脚の合わせ目を確認できます
- プレビューの背景色：🌓 ボタンで暗・中間・明を切り替えます（次回起動時も覚えています）
- 参考画像：見本にする画像をエディタの上に重ねて表示します。ヘッダーをドラッグで移動、右下の角でサイズ変更、スライダーで不透明度を変えられます。画像をクリックするとその色を取得します
- マイパレット：「＋」でいまの色を登録、右クリックで削除。次回起動時も残ります
- 明るく／暗くするブラシ（L / D キー）：なぞった所の色を一段ずつ明るく／暗くします。1回のドラッグで同じ場所が変わるのは1段だけです
- 塗りつぶしは面の中で止まります：同じ色が隣の面まで続いていても、クリックした面の外には広がりません
- 反転コピー：右半身（右腕・右脚と、頭・胴の右半分）を左半身へ、またはその逆へ、鏡写しでコピーします
- ブラシの太さ（[ / ] キー）：1〜4ピクセル。太いブラシも、中心がある面の外にははみ出しません
- パーツの表示切り替え：プレビュー下のボタンで、頭・胴・腕・脚を個別に隠せます。腕を隠して胴の側面を見る、といった使い方ができます
- 自動保存：作業内容は変更のたびに自動で保存されます。保存せずに終了してしまっても、次回起動時に復元するか聞かれます
- 範囲選択（S キー）：ドラッグで四角く選択し、選択範囲をドラッグか矢印キー（Shift で4ピクセルずつ）で動かせます。Ctrl+ドラッグで複製、Delete で消去、Esc で解除。動かした先の絵は、選択範囲の透明な部分では消えません
- パーツガイド：展開図に、パーツ名と面（前・後・右・左・上・下）を枠で表示します。右・左はキャラクター自身から見た向きで、点線の枠は重ね着レイヤーです
- 位置の連動：エディタでカーソルを置いた場所が3Dモデル上で光り、3Dモデルにカーソルを置くと展開図の対応する場所が光ります。左下に「右腕・前」のようにパーツ名が出ます
- 3Dプレビュー（重ね着レイヤー対応、ドラッグで回転・ホイールでズーム）
- 体型の切り替え：標準（クラシック / Steve、腕4px）/ スリム（Alex、腕3px）
- 重ね着レイヤーの表示切り替え（下のベース層を確認できます）
- PNG の読み込み・保存（読み込みはドラッグ＆ドロップでも可）
  - 旧形式の 64×32 スキンは 64×64 に変換して読み込みます（左腕・左脚は右側を反転して生成）
  - 読み込み時に体型を自動判定します
  - デスクトップ版は読み込んだ／保存したファイルを覚えていて、Ctrl+S で上書き保存します
- 元に戻す / やり直す（100手まで）
- 未保存の変更があるときは、閉じる前に確認します

ベース層の透明部分は、実際のゲームと同じく3Dプレビューでは黒く表示されます。

## 操作

| 操作 | キー |
| --- | --- |
| ペン / 消しゴム / 塗りつぶし / スポイト | P / E / F / I |
| 明るく / 暗く | L / D |
| 範囲選択 | S |
| ブラシを細く / 太く | [ / ] |
| 左右対称の切り替え | M |
| 色むらの切り替え | N |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Y |
| 保存 / 名前を付けて保存 | Ctrl+S / Ctrl+Shift+S |
| キャンバスの移動 | Alt+ドラッグ、または中ボタンドラッグ |
| キャンバスのズーム | ホイール |

## 開発

```sh
npm install
npm run dev            # ブラウザで開発（http://localhost:5173）
npm run electron:dev   # Electron で開発
npm run lint
```

## 配布用ビルド

```sh
npm run electron:build:win
```

`release/` にインストーラー版とポータブル版の exe が出力されます。
